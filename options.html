DeepSeek 侧边栏

在任何网页右侧使用 DeepSeek 官方网页版 · v—

安装成功 🎉 点击浏览器工具栏里的 DeepSeek 图标，即可在任意网页右侧打开侧边栏。

侧边栏加载的页面

默认加载 DeepSeek 官方对话页，登录状态与浏览器中一致。

请输入有效的 deepseek.com 地址

外观与交互

划词翻译

在任意网页选中文字，旁边会出现一个「译」按钮，点击即在浮窗里显示译文。 只有点按钮时才会把文本发出去，单纯选中不会触发任何请求。

保存在本机浏览器（storage.local，不参与同步），只用于向 api.deepseek.com 发起翻译请求。 去获取 API Key

运行状态

DeepSeek 官方页面通过 frame-ancestors 'none' 禁止被嵌入。 本扩展用 declarativeNetRequest 规则在「侧边栏子框架」请求中移除该响应头， 普通标签页访问 DeepSeek 时策略保持不变。
